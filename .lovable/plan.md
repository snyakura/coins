# Coinspace responsive frontend

## Build
- Recreate the shared Coinspace navigation and four referenced pages: Home, AI Analyser, Blog, and Live Market.
- Match the screenshots’ structure, spacing, typography, palette, data density, controls, cards, charts, and labels without adding new sections.
- Build responsive desktop, tablet, and mobile layouts with touch-friendly navigation and non-overflowing financial data.
- Implement Deposit and Withdraw as the referenced right-side conversational transaction panel, branded only as Coinspace Chatbot.
- Make visible controls functional with realistic in-memory prototype behavior: navigation, market periods, article filters/search, analysis upload state, transaction choices, and chatbot progression.

## Technical details
- Use TanStack Start routes and reusable React components with semantic Tailwind v4 design tokens.
- Use CSS/React chart rendering and local mock data; no external financial or payment services will be implied.
- Add unique metadata per page and verify rendering at desktop and mobile sizes.
